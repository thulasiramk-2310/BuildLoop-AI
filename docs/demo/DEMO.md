# Demo: from physical reality to verified engineering

## Problem
AI design tools draw circuits for an imaginary bench. Real builders have a specific pile of parts that changes mid-project.

## Differentiation
BuildLoop keeps a digital twin synced to the bench, validates designs with deterministic rules, gates hardware behind user approval, grades evidence honestly, and redesigns when a part disappears.

## 2-minute script (Demo Mode unless hardware ready)
| Time | Action | Say |
|---|---|---|
| 0–15 s | Show bench / synthetic frame | "Parts change; designs should too." |
| 15–35 s | Scan components, correct a resistor | "SAM segments; I confirm what vision can't know." |
| 35–60 s | Design tab: validation results | "Muse Spark proposes; rules decide." |
| 60–90 s | Assembly → authorize → bright/dark test | "Evidence level: sensor observed (simulated)." |
| 90–110 s | Remove photoresistor | "Design invalidated, redesign proposed." |
| 110–120 s | Phone-brightness design, before/after | "Substitute sensor, stated limits." |
